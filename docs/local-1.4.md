# Локальная сборка 1.4

Эта версия подготовлена только как локальный APK. Публикация на GitHub не выполнялась.

В разделе «Часы на блокировке» добавлен переключатель «ASCII-часы на экране блокировки», по умолчанию выключенный. При включении обои на блокировке показывают белые вытянутые ASCII-цифры HH:mm на чёрном фоне без даты и погоды. Используются текущее местное время и 24-часовой формат. Выбранные шрифт, символы и яркость применяются к часам. Для читаемости используется не менее 64 столбцов, размер знака ограничен 110% ширины ячейки.

На рабочем столе остаётся выбранный эффект. На Android 14+ учитываются флаги назначения движка обоев; для общего движка и старых версий используется состояние Keyguard. Изменение состояния проверяется только при видимых обоях. В режиме часов не декодируются новые кадры медиа и не рисуются волны от касаний. Маска цифр пересоздаётся при смене минут или размера экрана.

Отдельная кнопка предпросмотра показывает часы без включения настройки. Переключатель сохраняется и входит в пресеты. Для работы необходимо установить ASCII Flow на экран блокировки. Штатные часы телефона не скрываются приложением; доступные настройки их отображения зависят от One UI/Good Lock. Работа AOD не заявляется.

Проверены сборка, подпись, диапазон API 26–37 в тестах маршрутизации, выключенный режим, предпросмотр, переход суток и часовые пояса; также пройдены существующие тесты эффектов и пресетов. Проверки на физическом устройстве и точного визуального соответствия Android-отрисовки пока не было.
